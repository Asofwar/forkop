Исправления запуска и загрузки списков

- Добавлен резервный DNS для встроенных списков и удалённых JSON/SRS-наборов правил. Он используется при сбое системного DNS; если выбран прокси, загрузка остаётся через него.
- Обновление списков после холодной загрузки больше не прерывается раньше времени. Прежняя пауза ожидания сети сохраняется, пока резервный DNS сам не ответит.
- Исправлены ссылки с `@` в пути, в том числе jsDelivr с `@HEAD`.
- Повторный запуск уже работающего Forkop больше не считается ошибкой. Проверка чужих и дублирующихся процессов sing-box остаётся включённой.
- В журнале теперь видно, удалось ли автоматическое восстановление после неудачного запуска.
- Сохранены проверка HTTPS-сертификатов, ограничения загрузки при нехватке места и предыдущий рабочий кэш при ошибке.
- В Diagnostics и Components корректно определяется установленный вариант sing-box. Обычный пакет больше не отображается как tiny из-за старой отметки.
- Исправлена ошибка в разделе Diagnostics: проверка кэша системной информации прерывалась сразу после того, как в неё добавили определение пакета sing-box.
- Исправлено освобождение блокировок при неудачном запуске и перезагрузке. Раньше в этих редких случаях каталог блокировки мог остаться занятым и блокировать следующий запуск.
- Карточки Priority изначально свёрнуты и запоминают раскрытие при обновлении дашборда.
- При скачивании отчёта для поддержки появляется предупреждение: в файле могут быть приватные данные.

Сторонние HTTPS-подписки поддерживаются без ограничений провайдеров. Используется своё зеркало.

Автоматические проверки пройдены. На физическом роутере эта версия пока не проверялась — перед обновлением сохраните резервную копию конфигурации.
