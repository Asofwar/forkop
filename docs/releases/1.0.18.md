## Исправлено

- Forkop больше не остаётся выключенным после обновления пакета. Служба останавливается в `prerm`, но процесс sing-box завершается не мгновенно, и запуск успевал начаться, пока старый процесс ещё жив. Защита от чужих процессов в этот момент справедливо отказывала в старте. Теперь `postinst` ждёт его выхода и только потом поднимает службу.
- У бинарных наборов правил (`.srs`) появились резервные источники. Раньше они скачивались только с зеркала: если оно было недоступно или ещё не подхватило новый набор, набор просто не загружался. Теперь при сбое подключаются jsDelivr и GitHub — так же, как это давно работает для обычных списков.

## Добавлено

- Twitch во «Встроенные наборы правил №2».

## Обновление

Обновление через `opkg` и `apk` работает одинаково. Ничего вручную перезапускать не нужно.

Сторонние HTTPS-подписки поддерживаются без ограничений по провайдерам. Списки и зависимости идут со своего зеркала.

Автоматические проверки пройдены. На физическом роутере сборка не проверялась — перед обновлением сохраните резервную копию конфигурации.
