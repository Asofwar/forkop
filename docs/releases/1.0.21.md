## Мелкие исправления

- Чтение конфигурации cron сделано безопаснее. Forkop переписывает crontab целиком, чтобы убрать собственные задания, а список читался командой `crontab -l`. Её сбой неотличим от пустого crontab, и обратная запись могла стереть все посторонние задания на роутере. Теперь файл читается напрямую.
- Исправлено закрытие stdin при применении обновлённого поколения списков: вложенный вызов перезагрузки больше не наследует стандартный ввод рабочего процесса.

## Обновление

Обновление через `opkg` и `apk` работает одинаково. Ничего вручную перезапускать не нужно.

Сторонние HTTPS-подписки поддерживаются без ограничений по провайдерам. Списки и зависимости идут со своего зеркала.

Автоматические проверки пройдены.
