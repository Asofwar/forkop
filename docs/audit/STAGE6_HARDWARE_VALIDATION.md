## Дефекты

### P2 — upgrade оставляет Forkop остановленным при недоступном зеркале

- **Воспроизведение:** `apk add` трёх пакетов при недоступном `mirror.infotechtg.ru`; после завершения `/etc/init.d/forkop status` = not running.
- **Причина:** в `build.sh` post-upgrade/postinst объединены через `&&` — `migrate && mirror-migration.sh && forkop package_postinst`. Отказ `mirror-migration.sh` пропускает перезапуск, хотя prerm уже остановил сервис и оставил `/tmp/forkop-package-was-running`.
- **Происхождение:** та же цепочка есть в upstream `1.0.26` (`65787ed4`) и в `1.0.26-5`; регрессией Stage 6 не является. Откат на предыдущую версию проходит тот же путь.
- **Направление исправления:** запускать `package_postinst` независимо от результата миграции зеркала, сохраняя код ошибки.

### P3

1. Settings → Компоненты: кнопка «Выбрать версию» выходит за карточку Forkop X на 70 px при 1440 и 90 px при 768 и перекрывает заголовок соседней карточки (1024 — без переполнения).
2. Settings → Правила при 768: страница шире окна на 21 px, кнопки «Удалить» частично обрезаны.
3. На Обзоре нет карточки «Автоподбор DPI», предусмотренной дизайном G.1 и 6.9.
4. Согласование числительного при политике по умолчанию: «до 1 автоизменений в сутки», «Не больше 1 изменений в сутки».
5. Единицы трафика не локализованы: KB/s, B/s, KB, MB.
6. Сортировка в Мониторинге: «Скачать» рядом с «Отправлено».
7. Карточка узла в «Узлах и группах» показывает сырой тип «Direct».
8. RO-Обзор показывает теги outbound (`main-interface-1-out`), где admin видит имя интерфейса (`awg1`).
9. Diff снимка показывает `***` для значения, которого в снимке не было; UI-конвертер `'' → '—'` при этом не срабатывает. Поведение закреплено в `tests/config_snapshots.sh` — требуется решение, а не только правка.
10. Окно «Полное удаление» по умолчанию фокусирует диалог, а не «Отмена» (остальные подтверждения фокусируют «Отмена»).

Английские пункты меню, «Save & Apply», «Reset» и заголовок колонки «Name» принадлежат ядру LuCI и переводятся пакетом `luci-i18n-base-ru`, который на маршрутизаторе не установлен.

## Особенности окружения

- Тестовый PC работает через собственный VPN-клиент с маршрутом по умолчанию и внешним DNS. Поэтому браузерная проверка FakeIP на нём выдаёт предупреждение, а «HTTPS с PC» проверяет этот туннель, а не маршрутизацию Forkop.
- Вкладки headless-браузера, созданные через CDP, без эмуляции фокуса зависали на «Loading view…» при повторной навигации — для admin и RO, с перехватом и без. Это артефакт троттлинга фоновой вкладки, не дефект Forkop.
- RO-сессия без группы `unauthenticated` вызывает в LuCI окно «Session expired» (отказаны `session.access` и `luci.getFeatures`); реальные сессии эту группу получают всегда.
