## Обновление Forkop X через LuCI

- **Исправлено зависание запуска после обновления Forkop X из раздела компонентов.** Менеджер пакетов заменяет исполняемый файл под работающим процессом sing-box, и новая версия Forkop затем ждала рантайм, который уже невозможно опознать. Теперь старые процессы sing-box останавливаются до установки пакетов.

  Останавливаются только те процессы, которые действительно принадлежат procd: сверяются PID, время старта и полная командная строка, причём дважды подряд. Посторонний процесс с тем же именем не получит сигнал — вместо этого обновление остановится с явной ошибкой. Сама остановка ограничена по времени, поэтому зависший init-скрипт больше не может подвесить обновление целиком.

Раньше в этой ситуации помогало только обновление через скрипт установки вместо раздела компонентов в LuCI.

## Обновление

Обновление через `opkg` и `apk` работает одинаково. Существующие настройки не затрагиваются.
