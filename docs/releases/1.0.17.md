Обновление через opkg и защита рабочего состояния

- Исправлено обновление пакета на OpenWrt 24.10 (ipk/opkg): Forkop мог остаться выключенным после обновления. opkg на части сборок вызывает `prerm` без аргумента, и отметка «служба работала» стиралась — postinst потом не поднимал её обратно. Теперь решение принимается по фактическому состоянию службы. Установки через apk (25.12) этой ошибке не были подвержены.
- Остановка Forkop больше не разбирает DNS, nftables и маршрутизацию, если принадлежность процесса sing-box неоднозначна. Раньше политика снималась раньше, чем проверка успевала отказать, и чужой процесс мог остаться работать уже без защиты.
- Перезагрузка конфигурации проверяет принадлежность sing-box до захвата состояния и подготовки правил nftables, а не только когда рантайм уже выглядит неполным.
- Отчёт для поддержки больше не запускает полную проверку `sing-box check`. На роутерах с 256 МиБ памяти она могла кратковременно занять больше памяти, чем сам рантайм. Сырая конфигурация в отчёте сохранена.

Сторонние HTTPS-подписки поддерживаются без ограничений провайдеров. Используется своё зеркало.

Автоматические проверки пройдены. На физическом роутере эта версия пока не проверялась — перед обновлением сохраните резервную копию конфигурации.
