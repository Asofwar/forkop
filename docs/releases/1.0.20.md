## Обновление маршрутизации Discord

- Встроенный список Discord содержит общие Cloudflare Anycast-подсети. На них живут посторонние сайты и торрент-трафик, а маршрутизировались они как обычные сети Discord — то есть уходили в прокси целиком.
- Теперь эти общие диапазоны используются только для медиа-портов Discord: UDP 3478, 5000–5020, 19294–19344 и 50000–65535.
- Собственные подсети Discord маршрутизируются как прежде, включая фильтр портов секции, если он задан.
- Разделяется только список Discord. Отдельный встроенный список Cloudflare и все остальные списки не затронуты.
- При одновременно включённых списках Discord и Cloudflare в журнал добавлено предупреждение: широкие диапазоны Cloudflare могут увести посторонний трафик в прокси, и это зависит от порядка секций.

## Обновление

Обновление через `opkg` и `apk` работает одинаково. Ничего вручную перезапускать не нужно.

Сторонние HTTPS-подписки поддерживаются без ограничений по провайдерам. Списки и зависимости идут со своего зеркала.

Автоматические проверки пройдены.
